# Self-Driving Car Specialization Course

## Overview

This repository contains my notes, projects, and practice exercises completed while taking the **Self-Driving Car Specialization Course** offered by **Packt** on Coursera.

The course introduces the fundamental concepts behind autonomous vehicles, including system architecture, control systems, computer vision, robotics, simulation, and real-world implementation using JetBot and ROS.

---

## Course Information

- **Platform:** Coursera
- **Course:** Self-Driving Car Specialization Course
- **Instructor:** Packt - Course Instructors
- **Level:** Intermediate
- **Duration:** Approximately 9 Hours
- **Modules:** 6

---

## Learning Objectives

Throughout this course, I learned how to:

- Understand autonomous vehicle architecture
- Explore levels of driving automation
- Study sensors and software used in self-driving cars
- Design autonomous driving systems
- Implement vehicle control algorithms
- Learn PID controllers and Kalman Filters
- Perform object detection and computer vision tasks
- Build robotic simulations using ROS and Gazebo
- Develop mapping and localization workflows
- Deploy autonomous driving concepts on JetBot using NVIDIA Jetson Nano
